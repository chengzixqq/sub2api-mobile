三套布局，同一套配色

这一轮比较的是布局和信息架构：导航骨架、首页怎么组织、列表长什么样、详情怎么排、日志从哪进、充值怎么输。三套都用游标 Vernier 的黑白配色（浅色 / 深色），字体和形状各按自己的布局来。每个文件平铺 6 台可以点的 iPhone。

配色：游标 Vernier 石墨黑白 + 信号青同一份演示数据状态词与 Web 一致（错误 / 限流中 / 暂停 / 停用）可逆操作直接执行 + 撤销资金操作再确认，写明对象、站点、金额日志不占 Tab
A像 Linear 收件箱 / 值班工具

收件箱

打开就是“现在要处理什么”：逐个账号、原因、倒计时，可以直接测试或恢复。四个 Tab 对应四件高频事。

强
半夜救火最快：0 次点击看到哪个账号坏了，1 次点击处置
弱
早晚看概况时信息偏少；营收只占顶部一行
打开 6 屏交互深色
B像“健康”/“钱包”

卡片仪表盘

一面可以编辑的卡片墙：营收、账号健康环、渠道格、快捷充值各占一块，点卡片下钻。只有“摘要 / 浏览”两个 Tab。

强
早晚扫一眼最舒服；充值有大键盘；最像 iOS 原生 App
弱
密度最低，账号多时要多翻；没有好用的批量
打开 6 屏交互深色
C像“邮件”的邮箱列表 + 电子表格

表格工作台

没有 Tab 栏：根页是一串“视图”（需处理账号、余额低用户、上游错误…），每个视图是一张可排序、可横滑、带合计的表；详情是检查器，可以上一条 / 下一条逐行处理。

强
账号多、要精确对比和批量时最强；视图可以自己建
弱
学习成本最高；小屏横滑；不够“一眼看懂”
打开 6 屏交互深色
