Q1

统计分析页用哪种结构？

从概览“今日 · 更多统计”进来，默认显示今天。重点看三件事：第一屏能看到什么、怎么换时间范围、排行能看多深。可以点范围、点柱子、点日期说明行打开自定义日期，右上筛选里选“模型 · claude-opus-4”看看运行类图表的“显示全站”提示，再往下看排行和更多图表。从搜索目录进来时默认显示近 7 天。

Q2

“更多图表”二级页怎么组织？

共 11 张图：营收 1 张、用量 4 张、运行 6 张。从统计页的“全部图表”进来，比较三种方式下找图、翻图、扫数字的感觉。三种都有时间范围控件。可以在右上筛选里选一个模型，看运行类图表如何标明“不支持按模型筛选，显示全站”。

Q3

新建账号用哪种向导形式？

从账号页右上的 + 进入。三种形式的字段、校验和测试流程都一样，比的只是容器和翻页方式。建议一路点到“创建并测试”，看看三种状态下各有什么出口：测试进行中（可以“后台继续”）、测试通过（完成 / 查看账号）、测试未通过（修改凭据后重试 / 保留，暂停调度 / 保存为停用 / 删除账号…）。

Q4

OAuth 授权步骤怎么呈现？

初始是 Claude。Claude 和 Gemini 授权后页面会显示授权码，要回到 App 粘贴。OpenAI、Antigravity、Grok 会跳到 localhost：App 打开浏览器时临时监听回调端口，授权完自动回来并兑换令牌，粘贴只作兜底（可以返回第 1 步换成 OpenAI 看看）。代理放在“完成授权”旁边，兑换令牌和之后的请求都走这个代理，换代理不会重置授权进度。

Q5

编辑账号用哪种结构？

三台都是 Claude-官方-03（Anthropic OAuth，正在限流）。① ② 已带 3 项示范改动（并发数、加入同平台的“Claude 备用组”、代理换成 jp-01）。重点看三处：一是找到某个字段要滑多久，二是底部改动条（点开能看前后值，点某一项会跳到那一行，每项都能单独还原），三是“刷新令牌 / 重新授权”在编辑态里怎么标“立即生效”。① ② 是两种找分区的方式，字段和保存语义完全一样，都是先进入编辑态，最后统一保存一次。③ 是另一种编辑模型：没有单独的编辑页，详情页下面接可编辑的分区，每个分区单独保存。想看混合渠道警告：在 ① 或 ② 的“分组”里勾上“默认组”再保存。

Q6

（只在选了 ① 或 ② 时有效）凭据区怎么呈现？

选 ③ 时本题不适用：③ 固定用状态卡，而且立即生效。三台都是 OpenAI-备用-A（API Key 账号，401 凭据已失效），已经滚到凭据区。注意：已保存的密钥后端不返回，三种呈现都只显示“已设置 · 不可查看”。点“更换”，再点“粘贴”，可以看新密钥的样子（只有刚粘贴的新密钥才显示 前缀••••末4位）。C 可以点进凭据页，保存后回到编辑页，看入口变成“已更换 · 待测试”。OAuth 账号的样子可以在第 1 题的手机里看。

Q7

分组列表用哪种布局？

三个选项都从“搜索 → 分组”进入，点进去的详情统一用 A 样式，避免详情影响你对列表的判断。建议依次看：① 哪个最快让你看出“企业专线 0 个可用（红）”“标准组可用偏低（琥珀）”；② 右上角 + 新建分组，默认是“停用 + 专属”；③ 长按任一分组（桌面浏览器里用右键）会弹出和详情 ⋯ 一样的菜单；④ 网格可以点顶部计数格筛选，表格可以点表头排序；三种都能在搜索框输入“open”试试过滤。

Q8

分组详情用哪种布局？

三个选项打开的都是“标准组”（OpenAI，1/2 可用，告警中）。可以返回列表，再点企业专线（0 个可用）、测试组（已停用）、高级组（有限流倒计时）对比。可以试：“添加账号”（只列同平台账号）；“编辑分组”（改倍率、改专属/公开、移出账号都会弹确认，确认框写明站点；移出最后一个可用账号时是红色的“仍然保存”）；“记录与关联”里的错误请求、使用记录会进入按分组过滤的日志。三者下半部分（记录与关联、配置）相同，这道题只比上半部分和成员的呈现方式。

Q9

兑换码、代理、公告这类低频管理页，用哪种通用模式？（先用兑换码看）

两台手机都是兑换码页。两边的列表头、筛选胶囊（含“类型 ▾”菜单）、行内容、编辑和生成用的 sheet 完全一样，区别只在点开一行以后。左边进二级详情页：票券卡、大面额、码值遮罩加复制、使用与有效期、备注。右边在原地展开成卡片，不离开列表。注意两边信息量不同：详情页有票券卡，排版更舒展；展开卡片没有票券卡，更紧凑，适合连着处理好几条。所以这一题是在“层级清楚、内容丰富”和“少跳一层、精简”之间选。可以这样试：点一行，点眼睛显示码值，打开 ··· 菜单里的“删除兑换码…”（确认时要输入码的末 4 位）；再点一个“已使用”的码去编辑，会看到只能改备注。这一题选的模式会默认用到代理和公告上，第 2、3 题可以单独改。

Q10

代理页用哪种？（默认跟第 1 题一样，可以单独改）

两种模式换成代理再看一遍。演示数据和后端的真实行为一致：jp-tokyo-1 已过期，到期回退设的是“不回退”，所以账号还挂在上面，而且连接失败，这是需要人去处理的状态；us-east-2 也已过期，但回退设的是直连，账号已经被自动改走了；hk-02 再过 6 天到期。顶部横幅只统计还有账号在用的代理。可以这样试：点“测试连接”，结果直接显示在原地（只有这次会话里测过的才写“刚刚测试”，后端没有测试时间这个字段）；点 jp-tokyo-1 的“续期”，sheet 最上面就是有效期和状态，选好新有效期后状态会自动改回“正常”；在编辑里选“备用代理”，停用和已过期的代理是灰的，选不了。停用代理不弹确认，直接执行并提供撤销，因为已经在用的账号不受影响。

Q11

公告页用哪种？（默认跟第 1 题一样，可以单独改）

已读部分按后端实际有的能力来做：公告列表接口里没有已读计数，所以列表行只显示可见对象和“通知方式 · 有效期”，不画已读进度条；详情页只留一行“已读情况 ›”，点进去是和 Web 一样的逐个用户名单，可以搜索，可以按邮箱 / 用户名 / 余额排序，分页加载，每行显示余额、“符合条件 / 不符合”和已读时间（没读就显示未读）。没有已读 / 未读筛选，也没有汇总。编辑 sheet：可见对象在手机上只能设一个条件（订阅套餐多选，或者余额比较），已经是多条件的公告在手机上只读，要去 Web 改；有效期是“开始：立即 | 指定时间”和“结束：永久 | 指定时间”两行，选“指定时间”就出日期和时间选择。如果想要“已读 N / 符合条件 M”这样的汇总，需要后端新增 read-summary 接口，不在这一轮比较的范围里。

Q12

批量生成兑换码：一页表单，还是分步向导？

两种最后都进同一个确认框（写明站点、个数、每个的面额、合计），也是同一个结果页（逐行列出码值，可以全部复制）。演示里已经打开“高风险操作需要 Face ID”：余额合计超过 $100 时，确认之后还要过一次 Face ID。为了让你看到“结果待核对”这个状态，演示里第一次提交会故意模拟网络超时：页面会说明“请求可能已提交”，并给出幂等编号；点“用同一编号重试”才会看到正常的结果页。真机上服务器按编号幂等处理，不会重复生成。建议试试：面额填 10，数量填 20。

Q13

新建 / 编辑用户页用哪种结构？（新建和编辑共用同一结构）

三台手机都是从「用户 → 王小明 → ⋯ → 编辑用户」进来的。可以这样试：1. 改一下邮箱，再给并发数点“+”，看页面上哪里标出了“已改”，然后点导航栏的“保存”看回执。2. 把角色切到“管理员”再保存，走一遍二次验证：任意 6 位数字都能通过，000000 会报错；验证后还要再确认一次。3. 点「高级组」→“移除这个专属分组”，看“2 个 Key 会无法调用”的提示。4. 看立即生效的操作（余额、Key、平台限额、替换分组）放在哪里：A 放在分隔标题“以下操作立即生效”下面，B 放在第三段「Key 与限额」，C 不在这一页。5. 返回两次回到用户列表，点右上角 + 看新建页。最后在顶部切到深色再看一遍。

Q14

API Key 在页面里怎么呈现？（和上一题选哪种结构无关）

两台手机都停在分段结构的「Key 与限额」段。左边点任意一个 Key，会打开详情 sheet；右边点卡片头可以展开或收起。两边都试一下：1. 换分组：选“企业专线”会同时把这个分组授予用户，回执里可以撤销。2. 重置速率限制：5 小时 / 1 天 / 7 天三个窗口一起清零。这道题选出的样式，在 A 结构里用在 API Key 区，在 B 结构里用在第三段，在 C 结构里用在用户详情页。

Q15

要不要请后端加上“管理员替用户新建 / 停用 / 删除 Key”的功能？

后端目前对用户的 Key 只支持三件事：查看、换分组、重置速率限制，没有新建、停用、删除。你之前要求手机端能做这三件事。两台手机都打开了 Key「默认」的详情：左边保留虚线占位并标着“需后端新增”，点了只会弹出说明，不会真的执行；右边去掉了占位，只做后端已经支持的操作。
