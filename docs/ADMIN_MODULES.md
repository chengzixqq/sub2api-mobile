# 管理模块与滚动 RPM（2026-10-16）

本次沿用 `codex/native-ios-rebuild` 的同一套原生源码；后端接口参考共享源码 `e5ab7e4f4c136a8faf40fd06694ab0a6bf6f6925`。不更改后端、不部署服务器。以下描述功能与契约；构建和真机结果以 `ACCEPTANCE.md` 的最新记录及交付 manifest 为准。

## 入口与范围

底部新增“管理”，包含请求与错误日志、统计分析、分组管理。概览右上角可以打开统计分析；账号和分组详情可跳转到对应范围的日志、分析及账号列表。

请求记录读取 `GET /admin/usage`，使用 `count_mode=deferred`、时间倒序、按需分页。`total`/`pages` 可以为 null，按 `has_more` 判断是否继续；不要求大站点先执行全量计数。时间、用户、账号、分组、API Key、模型、请求 ID 等过滤由后端执行。实际扣费读取 `actual_cost`；上游成本读取 `(account_stats_cost ?? total_cost) × (account_rate_multiplier ?? 1)`，保留 Decimal 和缺失值。详情展示请求 ID、Token 分解、费用、时延及关联账号，不读取请求/响应正文。

错误日志分为客户端失败请求 `/admin/ops/request-errors` 和上游错误 `/admin/ops/upstream-errors`，按需读取同路径 `/:id` 的详情。两种日志的筛选能力不同，以当前 Web 和后端各自契约为准；上游错误也可能对应重试后恢复的请求。站点禁用 Ops 或权限不足时局部报告错误。正文、堆栈、完整 headers 不进入 DTO；可见摘要额外脱敏授权、Cookie、密钥、URL 中的凭据等字段。

## 账号

新增认证类型、分组、调度/限流状态筛选以及后端支持的排序。排序覆盖完整查询集合；当前服务端没有在用 RPM/并发排序，不对首屏作伪全局排序。选用 lite 列表；自定义显示字段与今日统计批量读取继续保留。

“前台自动刷新（30 秒）”默认关闭。开启后，在页面可见且应用处于前台时，串行刷新已经加载的所有分页；选择、编辑或批量操作期间暂停。刷新失败保留上次成功列表和更新时间，不重叠发请求。筛选变化和切站使用查询/会话身份检查拦截迟到结果。

左划/长按行或账号详情可以快捷编辑名称、备注、并发、优先级、成本倍率、负载因子及分组。先读取最新详情，只提交修改字段；未返回的原分组保留，明确取消才删除。凭据与 provider extra 不参与快捷编辑。批量选择最多 50 个已加载账号，支持暂停/启用调度和刷新凭据；确认展示站点及目标对象，结果逐账号展示成功、失败、未执行或不明确。写入无自动重试；超时不能视为失败后直接重发，必须先读取/核对。二次验证完成后需重新确认。

## 统计分析

今日、近 7 天、本月与一年以内自定义范围，支持账号、分组、用户和模型过滤；详情入口自动绑定对象。界面显示确切时间范围，开始包含、结束不包含；下拉刷新该固定范围，预设按钮更新截止时间到现在。

汇总 `/admin/usage/stats`、消费趋势 `/admin/dashboard/trend`、模型 `/admin/dashboard/models` 和分组 `/admin/dashboard/groups` 独立并发加载，使用同一范围、时区和筛选。显示请求数、K/M/B Token、实际扣费、上游成本、差额及平均时延。差额仅为扣费减成本，不能称为净利润。金额在解码、差额和显示舍入过程中使用 Decimal；只有图表坐标转 Double。缺失成本或实际消费显示不可用，不补零或标准费用。明细最新在上，图表支持横向查看。

## 分组

分页搜索、平台/状态筛选、详情、创建、稀疏编辑、启停和删除均调用 `/admin/groups` 的现有接口。可编辑名称、描述、倍率、专属、计费类型、RPM 及日/周/月限额；创建选择平台，编辑保留平台和未开放的路由/渠道配置。nil 表示不修改，取消限额显式发送 JSON null；删除/停用由服务器校验关联关系。结果不明先读取核对，不自动重发。

容量读取真实 `/admin/groups/capacity-summary`，不使用仍为占位实现的 `/:id/stats`。分组账号跳转到带过滤的账号页，通过账号快捷编辑管理归属；统计/日志使用真实聚合和记录接口。

## 概览 RPM

`/admin/dashboard/stats` 的 `rpm` 是服务端近 60 秒成功上游请求数；同时解码 `rpm_available`：true 的 0 才是真实零，false 显示“不可用”。未带该字段的旧站点保留数值并注明窗口由站点决定，不能宣称它是滚动 60 秒。TPM 仍为近 5 分钟平均，卡片分别标明两个口径。账号 `current_rpm` 已支持各平台/API Key/OAuth，读取同一滚动窗口；缺失值保持不可用。账号容量中的限流使用独立 `scheduling_rpm` 自然分钟计数，不把滚动计数与自然分钟限额作比。历史性能趋势仍按吞吐时间桶计算，统计范围与成功请求口径不同，不要求它与概览实时值相等。

## 验证边界

单元测试覆盖 API 路径和筛选、免计数分页、Decimal 精度、可用性、稀疏更新、null 限额、身份隔离、禁止写入重放与批量部分结果。XCUITest 使用显式 `-ui-testing` 内存数据，不操作生产。模拟器构建和未签名 IPA 不证明真实站点写入、验证码或签名后 iPhone 安装；这些需要在测试站点完成真机验收。
